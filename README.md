# Lock-inanator

A study companion / Focus tracker built with a Raspberry Pi 5, TFT Touch Display, Pi cam 2, and YOLO v8 vision intelligence.

- Interactive Pomodoro-style timer with a cute animated sprite companion who studies with you.
- Using the Pi Cam and Yolo Vision Model, it checks for distractions in the work area and tracks your focus streak.
- Using the Gemini API, it automatically sends the user's syllabus to create a custom to-do list that prioritizes the important topics.
- Uses Gemini to estimate the time required to learn each topic.
- Focus Streaks earn In-Game points, which could be used to redeem decor for the in-game room.
